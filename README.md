# 坦克大战 · Tank Battle

一个使用纯 HTML + Canvas + JavaScript 实现的经典《坦克大战》(Battle City) 网页版小游戏，单文件即可运行，无需任何依赖。

## 玩法

- 控制你的黄色坦克，在砖墙和钢墙之间穿梭。
- 消灭从上方不断出现的敌方坦克，守护底部中央的 **基地（鹰徽）**。
- 基地被击毁或生命归零，游戏结束。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` / `↑` · `S` / `↓` · `A` / `←` · `D` / `→` | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |

## 特色

- 可破坏的砖墙、不可破坏的钢墙
- 多种颜色的敌方坦克，关卡越高越强
- 随机掉落道具：❤ 加生命 · S 护盾 · B 全屏炸弹
- 音效、爆炸粒子、得分与关卡系统

## 运行

直接用浏览器打开 `index.html` 即可，或通过任意静态服务器：

```bash
npx serve .
```
